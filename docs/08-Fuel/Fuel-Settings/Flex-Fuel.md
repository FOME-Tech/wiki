# How Flex Fuel Works in FOME  

Flex fuel uses a sensor to determine the percentage of ethanol in the fuel lines which allows the ECU to change the fuelling to compensate for the ethanol content. The main advantage of this is the versatility to put any blend of fuel in your car from pure unleaded to pure ethanol without needing to adjust your tune \(if set up correctly\). Fortunately, setting up and tuning a flex fuel sensor isn't difficult as the ECU does most of the work for you.

## Sensor Configuration

Under _Sensors > Flex Fuel Sensor_, assign the correct input pin to the sensor. Additionally the sensor will need a 12V source and a ground.

## Fuelling Configuration

To set up the fuelling for a flex fuel sensor, your VE table should already be reasonably well tuned for unleaded petrol. In order to set up the ECU for flex fuelling, VE blend and adder tables are used to increase the fuel percentage added to the main VE table cells.

To set up the secondary fuel stoichiometric AFR, under _Fuel > Injection Configuration_ set _E100 Stoichiometric ratio_ to 9.0 for E100 fuel. This way the ECU knows to interpolate target AFRs between the _Stochiometric ratio_ being 14.7:1 for pure unleaded and the 9.0:1 ratio for pure ethanol. Just by setting this parameter, the ECU should run reasonably on ethanol as it factors the change in stoichiometric ratio into the fuelling calculations. In the likely case that the fuelling needs a slight tweak, the VE blend tables are used.

To set up the blend tables, under _Fuel > VE blend tables_ open _VE blend 1_ and _VE blend 1 config_. Set the blend 1 parameter to _Ethanol \(Flex\)% and populate the table with 0% ethanol all the way up to 85% or 100% ethanol depending if you want to run a maximum of E85 or E100 respectively. Then on the bias/Y axis, stat with 0% bias at 0% ethanol and set the maximum ethanol content to 100% bias \(this may be either 85% ethanol or 100% ethanol\). Then interpolate the remaining biases between these to form a linear bias curve. The relationship is not entirely linear but it is a good starting point. Ideally once VE is tuned properly at the maximum and minimum ethanol levels, data logs can be taken for varying ethanol contents and the biases adjusted accordingly. Tuning in lambda instead of AFR makes tuning flex fuel a lot easier as the sensor will always read 1.0 when the ratio is stoichiometric regardless of the ethanol content or stoichiometric AFR.

To tune the _VE blend config_ table, start by setting the X axis to match the RPM in your VE table and Y axis to the MAP values. Note that the blend table is 8x8 instead of the main table which is 16x16 so the blend table will need to be more crude but that is perfectly acceptable as it doesn't need as much detail as the main VE table. Once certain your 0% ethanol main VE table is well tuned, fill the car with your maximum ethanol fuel being either E85 or E100. Pure unleaded has a stoichiometric ratio of 14.7:1 compared to E85 at 9.8:1 and E100 at 9.0:1. Keep the blend table cells all at zero and cautiously take the car for a drive to log the lambda values. If the lambda remains at your targets across all operating conditions then amazing, job done. If not, check whether the percentage difference is approximately constant across all operating conditions or if it varies significantly. If the lambda is consistently running e.g. 5% lean at 1.05 lambda when target is 1.0 lambda, increase the blend table cells by up to 5 and continue adjusting until the lambda tracks the target across most operating conditions. If you find that some operating conditions run leaner than others such as at higher loads, you can increase those cells in the blend table separately. For example, the fuel pump could start struggling to keep up under higher loads with high ethanol fuel so extra VE is needed in those bias table cells to compensate for this. Note that the blend table cell values are multiplied by the bias table values to reach the percentage that the VE value is multiplied by. e.g. if the bias is 100% for E100 and the blend value for the whole blend table is 3, all VE values will be increased by 3% by multiplying them by 1.03, not adding +3 to the VE value.

## Ignition Blend Tables

Similarly to the VE blend tables, there are ignition blend tables which can be used in a similar manner to add or retard the timing. As ethanol cools the cylinders more than pure unleaded, usually it can run more ignition timing which is how it increases engine performance. 

To set up the blend tables, under _Ignition > Ignition blend tables_ open _Ignition blend 1_ and _Ignition blend 1 config_. Set the blend 1 parameter to _Ethanol \(Flex\)% and populate the table as you did for the VE blend table. For the blend table, set the load and RPM axis identically to the VE blend table. Populate the ignition blend table with the degrees of timing which you want to add to the base ignition table when running 100% ethanol. Properly tuning this table, like the base ignition will require a dyno and ideally working knock sensor. Start conservatively with 2-4 degrees of extra timing in the high load portions of the map and gradually increase. Adding 10 degrees of timing under full boost on full ethanol is not uncommon but you should be very conservative when increasing the timing as excessive detonation is what blows up engines. Like the VE blend tables, once the ignition map is tuned using E85 or E100, check for knock as you dilute the ethanol percentage and decrease the blend bias percentage if knock occurs.
